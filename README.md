# BeatLy

BeatLy is een MP3-speler waarmee je je eigen muziek kunt afspelen. Je kunt muziek pauzeren en naar het volgende of vorige nummer gaan. Voordat je muziek kunt afspelen, moet je eerst een map selecteren waarin je MP3-bestanden (nummers) staan. De applicatie heeft nog geen CSS.

<br>

## Installatie

1. unzip de file
2. open terminal
3. type deze commando `xattr -cr` en sleep de app achter deze command
